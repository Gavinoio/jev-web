# Jev 分享会演讲站（Slidev）

## 启动

```bash
npm install            # 首次（需要网络）
npm run dev            # http://localhost:3030
```

- **只开一个 `npm run dev`**：旧窗口没关时，旧进程会占着 3030 端口，新代码可能不生效。
- 全屏 `F` · 总览 `O` · 演讲者视图 `http://localhost:3030/presenter`（备注、计时只有你看到）
- 共 32 页：先讲五页 AI 基础（第 3–7 页），再认识 Jev（第 8 页），接着讲题型、判断与分流、三个外部案例、方案选型与工单验证，最后用变形输入框收束。
- 三个交互 Demo：第 10 页（四种输出，含实验性 Box）/ 第 14 页（工单分流）/ 第 31 页（会变形的输入框，倒数第二页）。全部为离线预设；批量分类与输入即判组件保留，但未接入当前页面。
- 第 19–20 页集中讲应用选择：用客服流程对照规则、分类与生成方案，再保留完整八个具体应用方向；原有适用标准和趋势页已合并，不再重复展开。
- 第 22–24 页为连续接入教学：服务端请求与响应示例、固定／自定义字段对照、四种题型的 criteria 与返回值；第 25 页继续讲题目边界。
- 演示全部使用浏览器内的确定性离线模拟，不调用 Jev、无需 Key，也不产生 API 费用。概率、把握度、框坐标均为演示数据，不是模型测量结果。
- 仅支持预设材料及原始题目、预设图片及目标；自定义内容或修改题目会明确提示不支持。Shift 支持预设示例，卡片内日期等仍按本地时间解析。
- 题型演示的前三种文字题共用一条“礼包扣款”工单，不显示其他示例按钮；Box 保留三个中文目标（搜索栏、7 号区块、拿清单的机器人）。工单分流默认沿用同一条“礼包扣款”工单与完全相同的三道题，再用一条含糊工单对比分流；其他预设数据保留备用。
- 模拟结果不包含真实 token 用量或网络延迟，也不能用于衡量模型准确率。
- 点击页面里的图片可放大，再点或按 Esc 关闭

## 导出 PDF（会后分发 / 断网备份）

```bash
npx playwright-chromium install chromium   # 首次，需要下载浏览器
npm run export
```

## 文件

- `slides.md` 网页幻灯片（32 页，含当前演讲者备注）；本轮仅更新网页版，论文案例与趣味实验页已移出主线
- `speech.md` 旧版完整演讲稿、数字速查表与 Q&A；尚未同步本轮网页重排，现场以网页备注为准
- `components/` Demo 与示意图组件，`styles/index.css` 深色科技主题
- `utils/shift.ts` 压轴 Demo 的题目、状态机和中文解析器（日期、金额、单位、算式……）；思路来自 [anishfn/shapeshift](https://github.com/anishfn/shapeshift)（MIT）
- `utils/jev.ts` 浏览器内的离线模拟；`functions/api/` 为保留的独立线上接口，演示不会调用它们
- `public/img/judgment-flow.svg`、`validation-loop.svg`、`intent-to-card.svg`、`news-filter.svg` 为本项目自绘的流程示意，不是模型测量结果
- 价格和外部案例数字沿用已有资料并保留来源；本轮网络检索不可用，未重新核验原文，不应作为当前报价或通用性能承诺
